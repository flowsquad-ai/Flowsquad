Setup Guide

Complete the 10-step Setup Wizard after installing FlowSquad — covering every field, every pre-requisite, and every configuration option from SSL/TLS to license activation.

ℹ️
This guide follows installation
You must have FlowSquad installed and running before starting this guide. If you have not yet installed FlowSquad, start with the Installation Guide. Once the application starts and you open it in a browser for the first time, the Setup Wizard launches automatically.

Database Configuration

FlowSquad requires an external PostgreSQL or MySQL database to store all product data, requirements, artifacts, and users. A small SQLite configuration database (flowsquad_engine.db) is created automatically alongside the application — you do not configure this here.

Pre-requisites

  • A running PostgreSQL 14+ or MySQL 8.0+ server accessible from the FlowSquad host
  • A dedicated database and a dedicated user account created in advance (recommended) — or FlowSquad can create the database for you if the user has CREATE DATABASE privileges
  • The firewall allows TCP on port 5432 (PostgreSQL) or 3306 (MySQL) from the FlowSquad server IP

Creating the Database User (PostgreSQL — recommended)

sudo -u postgres psql

CREATE DATABASE flowsquad;
CREATE USER flowsquad_app WITH PASSWORD 'replace-with-strong-password';
GRANT CONNECT ON DATABASE flowsquad TO flowsquad_app;
\c flowsquad
GRANT USAGE, CREATE ON SCHEMA public TO flowsquad_app;
GRANT ALL PRIVILEGES ON ALL TABLES IN SCHEMA public TO flowsquad_app;
GRANT ALL PRIVILEGES ON ALL SEQUENCES IN SCHEMA public TO flowsquad_app;
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT ALL ON TABLES TO flowsquad_app;
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT ALL ON SEQUENCES TO flowsquad_app;
\q

Creating the Database User (MySQL)

sudo mysql -u root
CREATE DATABASE flowsquad CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'flowsquad_app'@'%' IDENTIFIED BY 'replace-with-strong-password';
GRANT ALL PRIVILEGES ON flowsquad.* TO 'flowsquad_app'@'%';
FLUSH PRIVILEGES;
EXIT;

Step 4 — Authentication

Choose how users will sign in to FlowSquad. Multiple authentication methods can be enabled simultaneously — for example, Local Accounts (always on) plus LDAP for corporate users, plus SAML for executive accounts. Each method is independently configured and tested.

Local Accounts (Always Active)

Local authentication is always enabled and cannot be disabled. It provides the initial admin account and is the fallback if SSO is unavailable. Passwords are stored using bcrypt (12 rounds) — never in plain text.

  • Minimum password length is configurable (default: 8 characters)
  • Password complexity rules are configurable in Admin Panel -> Settings -> Security after setup
  • No external dependencies

LDAP / Active Directory

Pre-requisites: A dedicated LDAP service account with read-only directory access. The FlowSquad server must be able to reach the LDAP server on port 389 (LDAP) or port 636 (LDAPS).

Group-to-Role Mapping

Map AD/LDAP groups to FlowSquad roles. Users in the mapped groups automatically receive the corresponding role on every login.

  • CN=FlowSquad-Admins,OU=Groups,DC=company,DC=com -> Global Admin
  • CN=FlowSquad-ProdAdmins,OU=Groups,DC=company,DC=com -> Product Admin
  • CN=FlowSquad-Users,OU=Groups,DC=company,DC=com -> Regular User

Step 8 — License Activation

Upload your FlowSquad Enterprise license file (.lic). License validation is performed locally — no internet access is required.

Pre-requisites

  • A valid .lic license file from your FlowSquad account manager or the partner portal
  • For Docker or Kubernetes deployments: the FLOWSQUAD_CLUSTER_ID environment variable must match the ID used when the license was generated
  • For Linux bare-metal or Windows: /etc/machine-id (Linux) or the Windows machine GUID is used automatically

Uploading the License

  1. Click Upload License File and select your .lic file.
  2. FlowSquad validates the RSA-4096 signature, expiration date, and machine ID binding.
  3. If valid, license details are displayed: license type, company name, maximum products, and validity period.
  4. Click Activate & Continue.
ℹ️
Need a license?
FlowSquad ships with a bundled evaluation license (1 product, 30 days, full feature access) that activates automatically — no action needed to start evaluating. Contact support@flowsquad.ai to obtain an enterprise license for production use.

Troubleshooting

Database Connection Failed

Symptoms: "Connection refused" or "could not connect to server" when clicking Test Connection in Step 1.

Solutions:

  1. Confirm the database service is running: sudo systemctl status postgresql (Linux) or Get-Service postgresql* (Windows)
  2. Check that listen_addresses in postgresql.conf includes the FlowSquad server's IP (or '*')
  3. Verify the firewall allows the database port from the FlowSquad host: sudo ufw allow 5432/tcp
  4. Test the connection manually: psql -h <host> -U flowsquad_app -d flowsquad

LLM "Invalid API Key" (401)

Symptoms: Test Connection returns authentication error in Step 3.

Solutions:

  1. Verify there are no leading/trailing spaces in the pasted API key
  2. For OpenAI: check billing is active and the key is not restricted to specific IPs at platform.openai.com -> API keys
  3. For Anthropic: confirm the key starts with sk-ant- and was created in the correct workspace
  4. Generate a new key from the provider's console and re-enter it

LDAP "Invalid Credentials" (Correct Password)

Symptoms: Test Connection fails with "LDAP bind failed" even though the service account password is correct.

Solutions:

  1. Verify the Bind DN format exactly — use ldapsearch to confirm: ldapsearch -H ldap://ad.company.com -D "CN=svc-flowsquad,OU=ServiceAccounts,DC=company,DC=com" -W -b "DC=company,DC=com" "(sAMAccountName=svc-flowsquad)"
  2. Check the service account password has not expired in Active Directory
  3. If using LDAPS (port 636), ensure the server's certificate is trusted: import the CA certificate to the FlowSquad server's trust store
  4. Broaden the User Search Base to DC=company,DC=com to cover users across all OUs

SAML "Invalid SAML Response"

Symptoms: User authenticates at IdP but FlowSquad shows "Invalid SAML response" or "Signature validation failed".

Solutions:

  1. Verify the SP Entity ID in your IdP matches the auto-filled value in FlowSquad exactly, including port number: https://flowsquad.company.com:5000/saml/metadata
  2. Download the SP certificate from FlowSquad (Step 4 -> SAML -> "Generate SP Certificate" -> Download) and import it into your IdP
  3. Confirm both "Sign Assertions" and "Sign Document" are enabled in your IdP
  4. Check that the Email Attribute name in FlowSquad matches the attribute name your IdP sends

License "Validation Failed — Machine ID Mismatch"

Symptoms: License upload fails with machine ID or cluster ID mismatch error in Step 8.

Solutions:

  1. For Docker: verify FLOWSQUAD_CLUSTER_ID environment variable in docker-compose.yml matches the ID provided when the license was issued
  2. For Linux: check /etc/machine-id is correctly mounted into the container: - /etc/machine-id:/etc/host-machine-id:ro
  3. For Kubernetes: confirm the flowsquad-machine secret contains the correct cluster ID
  4. Contact support@flowsquad.ai with your deployment type and machine ID if re-issuance is needed

Setup Wizard Does Not Appear on First Load

Symptoms: Navigating to FlowSquad shows a login page or a blank page instead of the Setup Wizard.

Solutions:

  1. If the wizard was previously partially completed, navigate to /setup directly
  2. If the wizard is locked due to a previous failed run, stop FlowSquad, remove the flowsquad_engine.db file from the data directory, and restart — this resets all setup state (warning: all previous settings are lost)
  3. Check the application logs for startup errors: Linux: sudo journalctl -u flowsquad -f; Docker: docker compose logs -f

Frequently Asked Questions

When does the Setup Wizard appear?

The Setup Wizard launches automatically the first time you access FlowSquad in a browser after installation. It is also accessible to Global Admins at any time via the ⚙️ Setup button in the top navigation bar, or by navigating directly to /setup. The wizard must be fully completed before any other functionality is available on first run.

Can I skip optional wizard steps?

Steps 5 (Source Control) and 6 (Collaboration Tools) are optional — they can be skipped and configured later from Admin Panel -> Settings. Steps 1 (Database), 3 (LLM Provider), 7 (Admin Users), and 8 (License) are mandatory and must be completed before you can finish the wizard. Step 4 (Authentication) requires at minimum Local Accounts, which is already active by default.

What database does FlowSquad require?

FlowSquad uses two databases. The configuration database (flowsquad_engine.db) is always a local SQLite file — it is created automatically and requires no setup. The application database — which stores all product data, requirements, artifacts, and users — must be PostgreSQL 14+ or MySQL 8.0+. You must provision this database and user before running the Setup Wizard.

Can I change the LLM provider after setup?

Yes. Re-run the Setup Wizard via the ⚙️ Setup button in the top navigation bar to change the global default LLM provider. Per-product LLM overrides are available in each product's Settings -> LLM Configuration page without requiring a wizard re-run.

Can multiple authentication methods be active at the same time?

Yes. FlowSquad supports multiple authentication methods simultaneously. Local Accounts are always active. You can additionally enable LDAP, SAML 2.0, and/or OAuth2 — all at the same time. The login page shows login buttons for each enabled method. Users are matched to their account based on the email address returned by the authentication provider.
