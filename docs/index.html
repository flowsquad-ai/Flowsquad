Frequently Asked Questions

What is FlowSquad?

FlowSquad Enterprise is an AI-powered SDLC intelligence platform that helps engineering teams generate and manage software development artifacts. It connects your codebase, documentation, and project tools into a single workspace so you can generate requirements, epics, user stories, tasks, solution designs, and test cases -- all grounded in your actual product knowledge. Its core value proposition is: Analyze once. Reuse intelligence. No repeated LLM cost.

What workflow tabs does FlowSquad provide?

FlowSquad includes ten workflow tabs: Analyze (load codebase and documents), Refine (refine requirements with AI), Epic (generate epics), Story (generate user stories), Task (generate development tasks), Design (generate solution architecture), Test Cases (generate test scenarios), Quality Score (quick and deep quality analysis), Security Scan (OWASP Top 10 analysis), and AskProduct (natural language Q&A over your product knowledge base).

What is the difference between FlowSquad Evaluation and Enterprise?

The Evaluation tier gives a single user access to all workflow tabs with a single product workspace. Enterprise adds unlimited products, full RBAC with team members, SSO (LDAP, SAML, OAuth2), MFA (TOTP and email), per-product LLM provider configuration, Jira and Confluence integrations, database encryption, audit logging, PostgreSQL and MySQL support, and Kubernetes or Docker deployment.

Which AI (LLM) providers does FlowSquad support?

FlowSquad supports OpenAI (GPT-4, GPT-4o, GPT-4o-mini, GPT-4-turbo, GPT-3.5-turbo), Anthropic Claude (via the Anthropic API), GitHub Models (GPT-4o and GPT-4o-mini via the GitHub Models marketplace), and Ollama (fully local, air-gapped deployments -- Enterprise tier only). Each product can be configured with a different provider and model per operation type.

Where can I find the FlowSquad documentation?

FlowSquad documentation is available at flowsquad.ai/docs and is organised as a customer journey: Installation Guide (deploy the server), Setup Guide (complete the Setup Wizard), Admin Guide (manage products and users), User Guide (day-to-day workflow tabs), plus a Troubleshooting Index, Security Reference, and Integration Guide. Documentation is also built into the product itself, accessible from the Help menu.

What databases does FlowSquad support?

FlowSquad uses two databases: an application database (PostgreSQL recommended, MySQL also supported) that stores all product data, requirements, artifacts, and users; and a configuration database (flowsquad_engine.db, always SQLite) that stores settings, API keys, license information, and credentials. All sensitive values (API keys, passwords) in the configuration database are encrypted at the field level using Fernet AES-128-CBC.

Does FlowSquad support SSO and MFA?

Yes. FlowSquad Enterprise supports LDAP/Active Directory, SAML 2.0, and OAuth2 (GitHub, Google, Microsoft, Okta) for single sign-on. Multi-factor authentication (MFA) is supported via TOTP (authenticator app) and email one-time passwords. MFA is configurable per user in the admin panel.
