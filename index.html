How It Works

Five Steps from Codebase to Artifacts

Connect your repo, analyze once, then generate every SDLC artifact — requirements, designs, tests, and quality scores.

1

Connect Your Source

Point FlowSquad to your repository. Supports GitHub, GitLab, Bitbucket, Gitea, Azure DevOps, local folders, and document uploads. All major languages supported.

2

AI Deep Analysis

FlowSquad parses your code, extracts modules, dependencies, and patterns, then stores that intelligence internally. It is reused by all 10 workflow tabs — no repeated analysis cost.

3

Refine Requirements

Enter vague ideas. AI transforms them into complete requirements with acceptance criteria, dependencies, and completeness scores.

4

Generate Designs & Tests

Auto-create technical designs, architecture diagrams, and test cases aligned with YOUR codebase patterns.

5

Score Quality & Push to Jira

Get quality metrics, risk analysis (low/medium/high), OWASP security findings — then push epics, stories, tasks, and designs directly to Jira and Confluence.

Intelligence Reuse Flow

Analyze (once)  →  Cached Intelligence  →  Refine  →  Epic  →  Story  →  Task  →  Design  →  Test Cases  →  Quality Score  →  Security Scan  →  AskProduct

All 10 tabs query the same cached intelligence. Zero repeated analysis cost.

Security

Encryption at Every Layer. Identity at Every Gate.

FlowSquad is built for organisations where security is non-negotiable — air-gapped, encrypted end-to-end, with enterprise identity woven into every access point.

🛡️

Air-Gapped Deployment

Deploy entirely offline with Ollama. No outbound internet to any LLM provider. Suitable for classified, defence, regulated, or high-security environments — no exceptions needed.

🔐

Encryption at Every Layer

All sensitive configuration, credentials, and stored data are encrypted — at rest, in transit over TLS, and within the internal knowledge store. Nothing is ever stored in plain text, anywhere in the system.

🤺

MFA — TOTP & Email OTP

Multi-factor authentication via time-based one-time passwords (TOTP) and email OTP. Applied per user, enforced at login — no exceptions, no bypass for admin accounts.

🔗

SAML 2.0 Single Sign-On

Enterprise SSO via SAML 2.0 — integrates with Okta, Azure AD, ADFS, OneLogin, and any SAML-compliant identity provider. Centralise access and remove password sprawl.

🔓

OAuth2 & LDAP / Active Directory

OAuth2 federation with Okta, Azure AD, Google, Microsoft, Keycloak. LDAP and Active Directory for on-premise identity. Use what your organisation already runs — no new IdP required.

👔

Full RBAC — Three-Tier Access

Global Admin controls platform-wide settings. Product Admin manages per-product access and LLM config. Member role restricts to artifact generation only. Principle of least privilege, enforced.

📜

Immutable Audit Logs

Every user action — login, artifact generated, prompt edited, analysis triggered, access granted — is recorded with timestamp and context in tamper-evident logs. SOC 2, HIPAA, and GDPR reporting ready.

🗃

PostgreSQL & MySQL Support

Use your own managed database — PostgreSQL or MySQL — so audit data, product intelligence, and configuration live inside your security perimeter, under your backup and retention policies.
